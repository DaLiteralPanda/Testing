## 🚀 Space Explorer Demo Website

An interactive space-themed game built with HTML5, CSS3, and vanilla JavaScript.

### 🎮 How to Play

1. Open `index.html` in your web browser
2. Click "START MISSION" to begin
3. Use **Arrow Keys** or **WASD** to move your spaceship
4. Avoid asteroids and collect golden star power-ups
5. Survive as long as possible to achieve a high score!

### ✨ Features

- **Animated starfield background** with parallax scrolling
- **Progressive difficulty** - Game gets faster as you level up
- **Scoring system** - +10 points per asteroid avoided, +50 for power-ups
- **High score tracking** - Your best score is saved locally
- **Particle effects** - Explosion animations on power-up collection
- **Responsive design** - Works on different screen sizes

### 🛠️ Tech Stack

- Pure HTML5
- CSS3 with animations and gradients
- Vanilla JavaScript (no frameworks)
- Canvas API for game rendering
- LocalStorage for persistence

### 🚀 Running the Demo

Simply open `index.html` in any modern web browser. No build process or dependencies required!

Alternatively, run a local server:
```bash
python3 -m http.server 8000
# Then visit http://localhost:8000
```
